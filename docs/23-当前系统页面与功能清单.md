# 当前系统页面与功能清单

## 1. 文档目的

本文档按当前前端路由和后端接口，整理 SwapCampus 的页面、功能和主链路。

## 2. 系统总体定义

当前系统是一个面向校内师生的校园闲置交易与校园服务平台，包含四条主链路：

1. 二手商品交易
2. 用户与个人中心
3. 校园服务
4. 后台治理

## 3. 角色定义

- 游客
- 普通用户
- 管理员

## 4. 页面清单

### 4.1 首页 `/`

- 分类入口
- 活动区
- 推荐商品流
- 登录用户快捷入口

### 4.2 搜索页 `/search`

- 关键词搜索
- 价格筛选
- 成色筛选
- 信用筛选
- 商品卡片跳转详情

说明：

- 当前路由对登录用户开放；游客需先登录后访问。

### 4.3 校园服务页 `/campus-services`

- 浏览校园服务
- 筛选类别、意图、信用区间、价格、关键词
- 发布服务任务
- 接单、完成、暂停、结束

说明：

- 当前路由对登录用户开放。

### 4.4 收藏页 `/favorites`

- 登录用户商品收藏
- 游客本地临时想要
- 在售/失效分组
- 清理失效收藏

### 4.5 商品详情页 `/products/:id`

- 商品图片、价格、描述、卖家信息、推荐商品
- 想要/取消想要
- 发起会话
- 创建订单
- 举报商品或用户

### 4.6 用户公开主页 `/users/:id`

- 用户信用摘要
- 在售商品
- 收到的评价
- 关注/取消关注

### 4.7 发布页 `/publish`

- 商品发布
- 商品图片上传
- 发布规则查看
- 校园服务发布工作台

### 4.8 发布规则页 `/publish/rules`

- 允许分类
- 禁售词
- 白名单电器
- 审核流程说明

### 4.9 消息页 `/messages`

- 会话列表
- 消息明细
- 文本和附件发送
- Socket.IO 实时追加

### 4.10 订单页 `/orders/:id`

- 订单详情
- 确认面交
- 取消
- 完成
- 评价
- 申诉

### 4.11 订单快照页 `/orders/:id/snapshot`

- 展示订单生成时的商品快照

### 4.12 信用中心 `/credit-center`

- 信用摘要
- 签到
- 任务
- 积分账本
- 奖励兑换

### 4.13 个人中心 `/profile`

- 用户资料
- 信用摘要
- 我发布的
- 我卖出的
- 我买到的
- 收藏
- 浏览历史
- 关注列表
- 收到的评价

### 4.14 个人资料详情 `/profile/detail`

- 独立资料和实名详情页

### 4.15 后台 `/admin`

- 运营总览
- 商品审核
- 订单治理
- 校园服务治理
- 举报处理
- 申诉处理
- 用户治理
- 审计日志

### 4.16 登录页 `/login`

- 登录
- 注册

## 5. 访问控制

- 游客：可访问首页、商品详情、用户主页、登录页
- 普通用户：可访问完整交易、收藏、信用中心、个人中心、校园服务和消息
- 管理员：可访问后台

## 6. 当前实现结论

- 登录用户收藏已正式接入后端
- 校园服务已拆分为列表、详情、订单和收藏
- 商品和校园服务均支持图片上传
- 消息、订单、举报、申诉和信用中心均已形成可演示闭环
