# 答辩材料提纲

## 1. 背景

- 校园闲置交易信息碎片化
- 需要统一交易、沟通、治理和信用

## 2. 系统定位

- 校内师生使用
- 真实闭环
- 课程设计可交付

## 3. 核心功能

- 注册登录
- 商品浏览与发布
- 收藏与推荐
- 订单、评价和申诉
- 消息与校园服务
- 信用中心
- 后台治理

## 4. 技术与部署

- React + NestJS + Prisma
- MySQL + MinIO + SuperTokens + Meilisearch
- Docker Compose 一键启动

## 5. 数据口径

- 默认初始化为空库
- 可选演示种子可重建
- 不再把演示种子误写成默认运行态

## 6. 展望

- 完整 IM
- 更细粒度治理
- 更高自动化覆盖率
