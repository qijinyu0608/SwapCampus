# 项目计划

## 1. 推进方式

本项目按“小步迭代、边实现边验收、边同步文档”的方式推进。

## 2. 已完成阶段

### 阶段一：基础工程

- 前后端仓库结构
- Docker Compose
- Prisma schema
- 基础页面骨架

### 阶段二：主链路

- 商品浏览、搜索、详情
- 注册登录
- 商品发布
- 订单创建与消息联动

### 阶段三：治理与扩展

- 后台审核
- 举报与封禁
- 校园服务
- 收藏持久化
- 信用中心
- 订单评价与申诉

### 阶段四：交付收口

- 对象存储与图片上传
- 文档归档整理
- 截图、验收、部署说明

## 3. 当前进行中

- 文档与当前实现持续对齐
- 演示脚本与答辩材料精修

## 4. 后续增强

- 完整 IM 能力
- 更高前端自动化覆盖率
- 更细粒度风控与治理策略
