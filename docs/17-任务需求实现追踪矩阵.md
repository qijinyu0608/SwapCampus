# 任务需求实现追踪矩阵

## 1. 目的
本矩阵用于把课程任务书、项目需求、当前实现和验收证据放在同一张表中，避免出现“代码完成了但文档不可追溯”或“文档写了但无法验证”的交付问题。

## 2. 使用说明
- `需求来源`：对应课程设计任务书、开题目标或需求规格说明书中的要求。
- `当前实现`：对应仓库中的真实模块、页面或工程资产。
- `验证证据`：对应测试报告、验收记录、运行命令或页面证据。
- `状态`：使用 `已完成 / 已完成但可继续增强 / 后续增强` 三种口径。
