# 验收与演示记录

证明当前仓库不是静态页面集合，而是具备真实数据、真实接口、可复现部署和可演示主链路的系统。

## 4. 演示主链路

### 4.1 商品链路

- 首页浏览商品
- 打开商品详情
- 收藏商品
- 创建订单
- 查看订单详情与快照

### 4.2 消息链路

- 打开消息页
- 查看会话
- 发送文本或附件
- 观察实时追加

### 4.3 校园服务链路

- 进入校园服务页
- 发布校园服务
- 接单或预约
- 完成服务

### 4.4 个人中心与信用中心

- 编辑资料
- 查看关注、收藏、浏览历史和评价
- 进入信用中心签到、领取任务、查看积分流水

### 4.5 后台治理

- 商品审核
- 举报处理
- 订单申诉处理
- 用户封禁 / 解封
- 实名审核
