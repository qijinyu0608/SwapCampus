# 验收与演示记录

## 1. 验收目的

本次验收的重点，是确认当前仓库并非静态页面集合，而是一套具备真实数据、真实接口、可复现部署和可演示主链路的系统。

## 2. 当前环境

- 项目根目录：`/home/th1rt3en/dev/forge/SwapCampus`
- 前端：`http://127.0.0.1:5178`
- 后端：`http://127.0.0.1:3001/api`
- 容器编排：Docker Compose

## 3. 构建与启动验证

构建与启动验证包含后端测试、前端构建、容器初始化与启动，以及健康检查和关键接口访问，分别使用 `npm test --prefix backend`、`npm run build --prefix frontend`、`make init`、`make start`、`curl http://127.0.0.1:3001/api/health`、`curl http://127.0.0.1:3001/api/products/publishing-rules`、`curl http://127.0.0.1:3001/api/products/dashboard`、`curl http://127.0.0.1:3002/health` 和 `curl -I http://127.0.0.1:5178` 进行核对。

## 4. 演示主链路

### 4.1 商品链路

- 首页浏览商品
- 打开商品详情
- 收藏商品
- 创建订单
- 查看订单详情与快照

### 4.2 消息链路

- 打开消息页
- 查看会话
- 发送文本或附件
- 观察实时追加

### 4.3 校园服务链路

- 进入校园服务页
- 发布校园服务
- 接单或预约
- 完成服务

### 4.4 个人中心与信用中心

- 编辑资料
- 查看关注、收藏、浏览历史和评价
- 进入信用中心签到、领取任务、查看积分流水

### 4.5 后台治理

- 商品审核
- 举报处理
- 订单申诉处理
- 用户封禁 / 解封
- 实名审核
