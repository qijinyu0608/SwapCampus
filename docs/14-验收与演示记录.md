### 4.4 举报封禁与恢复验收
- 验收日期：`2026-06-03`
- 验证对象：
  - 举报：`#6`
  - 目标用户：`#40`
  - 账号：`user6@stu.swapcampus.cn`
- 验收步骤：
  1. `PATCH /api/reports/6/resolve`，请求体 `{"handledBy":22,"resolutionNote":"顺序验收：举报封禁","nextStatus":"BAN_USER"}`
  2. 查询 `GET /api/users/moderation/list`，确认 `id=40` 的 `isBanned=true`
  3. `POST /api/auth/login` 使用 `user6@stu.swapcampus.cn / SwapCampusUser2026`
  4. `POST /api/reports` 使用 `reporterId=40` 再次发起举报
  5. `PATCH /api/reports/6/resolve`，请求体 `{"handledBy":22,"resolutionNote":"顺序验收：解除封禁","nextStatus":"UNBAN_USER"}`
  6. 再次查询 `GET /api/users/moderation/list`，确认 `isBanned=false`
  7. 再次执行登录
- 验收结果：
  - `BAN_USER` 后目标用户真实变为封禁状态
  - 被封禁账号登录返回 `403`
  - 被封禁账号发起举报返回 `403`
  - `UNBAN_USER` 后登录恢复 `201`
- 结论：举报处理、用户治理、登录拦截和恢复流程已形成真实闭环
