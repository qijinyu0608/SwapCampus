# 团队分工与贡献说明

## 建议分工
- 组长：项目管理、需求跟踪、答辩协调
- 前端负责人：页面开发、联调、用户体验
- 后端负责人：接口、数据库、聊天服务
- 测试文档负责人：测试执行、缺陷跟踪、文档维护

## 贡献记录方式
- 通过 Git 提交历史记录代码贡献
- 通过文档修改记录体现过程贡献

## 当前项目实际贡献类型
- 产品与视觉：完成首页、发布页、消息页、个人中心、后台页的统一视觉和产品化表达
- 后端与数据库：完成用户注册、商品发布、订单创建、消息发送、后台商品审核与种子数据导入
- 测试与运维：完成本地构建、Docker Compose 启动、接口联调和课程设计文档同步
