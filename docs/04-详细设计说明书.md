# 详细设计说明书

## 1. 认证模块

关键接口：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

当前实现：

- 基于 SuperTokens 建立会话
- 注册支持头像与学生证图片上传
- 业务用户表与认证用户保持同步

## 2. 商品模块

关键接口：

- `GET /api/products`
- `GET /api/products/home-recommendations`
- `GET /api/products/publishing-rules`
- `GET /api/products/dashboard`
- `GET /api/products/:id`
- `POST /api/products`
- `POST /api/products/:id/contact`

当前实现：

- 发布需要至少一张图片
- 图片先上传到 MinIO，再把 URL 写入 `ProductImage`
- 商品发布走本地规则 + LLM 审核
- 发布成功后当前直接进入 `ON_SALE`

## 3. 收藏模块

关键接口：

- `GET /api/favorites`
- `POST /api/favorites/:productId`
- `DELETE /api/favorites/:productId`

当前实现：

- 登录用户收藏落库
- 游客保留本地临时想要
- 收藏状态与推荐行为联动

## 4. 订单模块

关键接口：

- `GET /api/orders`
- `GET /api/orders/:id`
- `POST /api/orders`
- `PATCH /api/orders/:id/meetup`
- `PATCH /api/orders/:id/cancel`
- `PATCH /api/orders/:id/complete`
- `POST /api/orders/:id/reviews`
- `POST /api/orders/:id/appeals`

当前实现：

- 创建订单后自动生成或绑定会话
- 订单保留商品快照
- 支持评价与申诉

## 5. 消息模块

关键接口：

- `GET /api/messages/conversations`
- `POST /api/messages/conversations`
- `GET /api/messages/conversations/:id`
- `POST /api/messages/conversations/:id`
- `POST /api/media/messages`

当前实现：

- REST 负责读写
- Socket.IO 负责 `message:new` 房间推送
- 握手与会话订阅都带认证校验

## 6. 校园服务模块

关键接口：

- `GET /api/campus-services`
- `GET /api/campus-services/:id`
- `POST /api/campus-services`
- `PATCH /api/campus-services/:id`
- `POST /api/campus-services/:id/orders`
- `POST /api/campus-services/:id/pause`
- `POST /api/campus-services/:id/reopen`
- `POST /api/campus-services/:id/end`
- `GET /api/campus-service-orders`
- `GET /api/campus-service-orders/:id`
- `POST /api/campus-service-orders/:id/confirm`
- `POST /api/campus-service-orders/:id/reject`
- `POST /api/campus-service-orders/:id/complete`
- `POST /api/campus-service-orders/:id/confirm-complete`
- `POST /api/campus-service-orders/:id/cancel`
- `GET /api/campus-service-favorites`
- `POST /api/campus-service-favorites/:listingId`
- `DELETE /api/campus-service-favorites/:listingId`

当前实现：

- 支持 `REQUEST / OFFER`
- 支持发布、接单、收藏、完成和消息联动

## 9. 媒体模块

关键接口：

- `POST /api/media/images`
- `POST /api/media/messages`
- `GET /api/media/files`

当前实现：

- 商品图片、头像、学生证、校园服务图片和消息附件统一走媒体模块
- MinIO bucket 启动时自动检查和创建

## 10. 当前边界

- 消息未读、在线状态和断线补偿未落库
- 更完整的认证会话治理和更高自动化覆盖率仍可继续补强
