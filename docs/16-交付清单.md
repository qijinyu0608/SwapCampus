# 交付清单

## 1. 交付方式

- 项目根目录：`SwapCampus/`
- 交付内容：整个仓库目录
- 推荐启动入口：`make init`、`make start`

## 2. 交付目录说明

- `frontend/`：前端页面、构建配置与静态资源
- `backend/`：后端接口、认证、Prisma、媒体与种子脚本
- `docs/`：当前有效课程文档
- `docs/archive/`：历史过程材料与已归档专题
- `agent/`：当前有效工程规范
- `infra/`：架构说明、压测计划与辅助说明
- `artifacts/screenshots/`：页面截图证据
- `docker-compose.yml`：本地部署入口
- `Makefile`：常用工程命令
- `.github/workflows/ci.yml`：基础 CI

## 3. 运行前置条件

- 必需环境：Docker Desktop
- 可选环境：Node.js 20+、npm 10+

## 4. 默认端口

- 前端：`5178`
- 后端：`3001`
- MySQL：`3306`
- Meilisearch：`7700`
- MinIO API：`9000`
- MinIO Console：`9001`
- SuperTokens PostgreSQL：`5433`

## 5. 默认初始化口径

- 默认不预置演示账号
- 默认不自动导入商品、订单、消息、举报或校园服务数据
- `make init` 只建表并执行空库初始化检查

## 6. 可选演示数据口径

如需重建演示数据，可执行：

```bash
cd backend && npm run db:reset-and-seed-demo
```

当前可选演示种子规模：

- 用户：10
- 商品：30
- 校园服务：18
- 商品订单：6
- 校园服务订单：4
- 举报：4

## 7. 重置方式

清空容器与卷：

```bash
docker compose down -v
```

重新初始化：

```bash
make init
make start
```

## 8. 已验证命令

- 后端测试：`npm test --prefix backend`
- 前端构建：`npm run build --prefix frontend`
- 容器初始化：`make init`
- 默认运行态启动：`make start`
- 健康检查：`curl http://127.0.0.1:3001/api/health`
- 演示数据重建：`npm run db:reset-and-seed-demo --prefix backend`
