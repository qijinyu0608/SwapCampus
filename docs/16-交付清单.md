# 交付清单

## 1. 项目位置
- 项目根目录：`/Users/qijinyu/Documents/software-design/SwapCampus`
- 交付方式：直接交付整个 `SwapCampus` 目录
- 启动入口：`docker compose up -d --build`

## 2. 交付目录
- `frontend`：前端页面与构建配置
- `backend`：后端接口、认证、Prisma 与种子脚本
- `docs`：课程设计文档与交付材料
- `infra`：架构说明与容量评估补充材料
- `artifacts/screenshots`：页面截图证据
- `docker-compose.yml`：一键部署入口
- `Makefile`：常用工程命令
- `.github/workflows/ci.yml`：持续集成配置

## 3. 运行前置条件
- 必需环境：Docker Desktop
- 可选环境：Node.js 20+、npm 10+
- 不需要单独安装本地 MySQL

## 4. 默认端口
- 前端：`5178`
- 后端：`3001`
- MySQL：`3306`
- MinIO Console：`9001`

## 5. 默认账号
- 当前版本不再预置默认账号、种子用户或统一默认密码

## 6. 首次部署结果
- 自动创建数据库表结构
- 默认不再自动导入商品、用户、消息、订单、举报与校园服务演示数据

## 7. 重置方式
- 清空容器与数据卷：
```bash
docker compose down -v
```
- 重新初始化：
```bash
docker compose up -d --build
```

## 8. 已验证命令
- 后端测试：`npm test --prefix backend`
- 前端构建：`npm run build --prefix frontend`
- 容器启动：`docker compose up -d --build`
- 管理员登录接口：`POST /api/auth/login`
- 举报处理与封禁恢复闭环：`PATCH /api/reports/:id/resolve`
