# 概要设计说明书

## 1. 系统架构

当前系统采用前后端分离架构：

- `frontend`：React + Vite
- `backend`：NestJS 单体后端
- `mysql`：业务主库
- `supertokens-db` + `supertokens`：认证与会话
- `minio`：对象存储
- `meilisearch`：搜索

## 2. 设计原则

- 单体按领域模块拆分
- 文档与代码同仓维护
- 部署通过 Compose 复现
- 认证、媒体、搜索、交易分层清晰

## 3. 核心模块

- 用户与认证
- 商品
- 订单与评价
- 收藏与行为
- 消息
- 校园服务
- 信用中心
- 举报与后台治理

## 4. 当前关键实现特征

- 商品发布已接入图片上传、对象存储和 LLM 审核
- 登录用户收藏已走 `Favorite` 表
- 校园服务已采用 `listing + order` 双层模型
- 订单支持评价、申诉、快照和会话联动
- 消息支持会话鉴权和 Socket.IO 房间推送
- 信用中心支持签到、任务、账本和兑换

## 5. 部署概要

- `db-init` 只建表，不自动导入演示数据
- 可选演示数据通过 `db:reset-and-seed-demo` 重建
- 前端由 `nginx` 托管静态构建产物

## 6. 当前边界

- 实时消息仍为演示级能力
- 完整会话治理、交互级测试和更细粒度风控仍可继续增强
