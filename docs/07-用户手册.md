# 用户手册

## 1. 适用范围
本手册面向当前系统的三类使用者：
- 游客：只浏览商品与详情
- 普通用户：浏览、发布、沟通、下单
- 管理员：审核商品、查看举报与留痕

## 2. 登录与身份说明
### 2.1 登录入口
访问首页后，点击右上角 `登录` 进入登录页。

### 2.2 支持的使用方式
- 使用学号、姓名、邮箱、密码注册普通用户
- 使用学号或邮箱登录已有用户
- 以游客身份直接进入浏览模式
- 以管理员默认账号进入后台

### 2.3 当前身份规则
- 注册成功后，系统会把当前登录用户信息保存在浏览器本地
- 普通用户同时具备买家和卖家能力，不做互斥拆分
- 游客模式不可发布、发消息和下单
- 已登录状态下，头部提供 `退出登录` 入口，点击后退出当前账号并回到首页

## 3. 首页浏览
### 3.1 首页内容
首页默认展示：
- 搜索框
- 一级分类面板
- 分类右侧活动主区与快捷入口
- 商品推荐流
- 折叠式筛选区

### 3.2 商品卡信息
商品卡默认展示：
- 商品标题
- 价格
- 分类与成色弱标签
- 卖家信息
- 推荐理由或信用提示
- 常用面交点位或同校标识

点击商品卡即可进入详情页，查看更多描述、交易参考、面交信息和卖家信息。

### 3.3 首页筛选
首页支持以下筛选：
- 排序
- 价格区间
- 成色
- 交易方式

筛选区默认折叠，点击后展开。

### 3.4 分类面板
- 一级分类默认常驻显示
- 首页顶部不再重复展示第二套一级分类入口
- 二级分类默认隐藏
- 选中或悬停某个一级分类后，右侧才展开对应二级分类
- 分类栏为窄栏，右侧活动区为主要浏览区域
- 分类栏右侧默认展示“主活动卡 + 四个副卡”的校园活动界面与快捷入口
- 具体商品流下沉到活动区下方，更接近日常校园闲置浏览顺序
- 在较窄屏幕下，仍优先展示活动区，再显示分类和商品流

## 3.5 校园服务子模块
头部导航提供 `校园服务` 入口，用于承接不适合直接混入二手商品流的校内服务场景。

当前独立展示的服务类型包括：
- 校园跑腿
- 代办代取
- 校内拼单
- 临时帮忙

页面默认展示：
- 服务概览
- 服务热度看板
- 热门委托列表
- 校内服务规则提示

## 4. 商品详情
商品详情页提供以下信息：
- 商品主图与缩略图切换
- 默认首屏只展示价格、状态、少量交易参考和主操作
- 卖家学院、实名状态、信用信息
- 折叠后的更多标签、规则状态和统计信息
- 同类推荐商品

详情页桌面宽度下默认采用左图右信息的双列结构；在较窄屏幕下再切换为单列。

如果需要查看更多说明，展开 `更多` `商品说明` `交易参考` `对方在售` 等折叠块即可。

## 5. 想要与收藏
点击商品卡或详情页中的 `想要` 按钮，可把商品加入“想要”列表。

在“想要”页面中：
- 可查看已收藏商品
- 可进入详情页
- 可直接取消想要
- 默认只展示轻量信息，不额外铺开信用说明
- 当前版本会按当前浏览器登录用户分别保存想要列表
- 普通用户的想要行为会同时作为推荐信号参与首页排序

## 6. 发布商品
### 6.1 发布路径
登录普通用户后，点击顶部 `发布` 进入发布页。

### 6.2 发布步骤
1. 填写标题
2. 选择分类
3. 输入价格
4. 选择成色
5. 先直接填写商品描述
6. 如有需要，再展开 `补充信息` 填写标签
7. 提交审核

### 6.3 发布结果
- 提交成功后，系统返回新商品 ID
- 新商品状态为 `PENDING`
- 管理员审核通过后，商品进入首页展示
- 发布页首屏默认只保留主表单，`常用写法` `发布提示` `规则` 等辅助信息后置到右侧折叠区
- 如果标题、描述或标签命中禁售内容，或者宿舍电器不符合白名单规则，系统会直接阻止提交或拒绝上架
- 发布页会展示允许分类、禁售词提示、宿舍电器白名单、审核流程和交易安全提醒

## 7. 消息沟通
消息页支持：
- 查看会话列表
- 查看当前会话消息
- 发送文本消息
- 校园服务任务会话与商品/订单会话统一在此查看
- 游客状态下只展示轻量只读提示，不直接铺开会话双栏

发送成功后，消息会写入数据库，并刷新当前会话内容。
当前版本已接入演示级实时推送，打开同一会话时新消息可直接追加到消息流。
会话列表默认只展示商品、最近预览和时间，当前会话区域保持紧凑消息流展示，单条消息按内容宽度收窄。

## 8. 订单与个人中心
### 8.1 下单
在商品详情页点击 `约面交` 可创建订单。

订单创建后：
- 后端写入订单记录
- 系统同步生成关联会话
- 用户会进入个人中心的“我买到的”订单列表
- 商品会暂时从公开交易流中隐藏，避免重复下单

后续订单操作：
- 在 `待约定` 状态下，可联系对方、确认线下面交时间地点或取消订单
- 在 `待面交` 状态下，可修改约定、确认线下面交完成或取消订单
- 在 `待评价` 状态下，可提交评分与评价内容
- 订单完成后，商品标记为已售

当前交易方式只支持校内线下面交，不包含线上付款、发货、物流和收货流程。

### 8.2 个人中心
个人中心当前展示：
- 当前登录身份
- 信用分与实名状态
- 线下面交订单
- 已发布商品
- 想要商品数量
- 订单支持 `全部`、`待约定`、`待面交`、`待评价`、`已完成`、`已取消` 筛选
- 侧栏支持切换 `我发布的`、`我卖出的`、`我买到的`
- 个人资料入口会打开独立详情页，编辑资料入口仍保留在个人中心内

### 8.3 编辑资料
个人中心支持编辑以下信息：
- 昵称
- 邮箱
- 真实姓名
- 学院
- 手机号

保存成功后：
- 页面中的资料信息会立即刷新
- 当前浏览器保存的登录用户昵称与邮箱会同步更新
- 信用摘要中的实名和学院信息会同步刷新

### 8.4 个人资料详情
点击侧栏 `个人资料` 会打开独立资料详情页。

详情页展示：
- 昵称、邮箱、学号和账号类型
- 真实姓名、学院、手机号和实名状态
- 信用分、信用等级、成交数、进行中订单、待评价订单和消息回复率

## 8.5 举报商品
在商品详情页可以点击 `举报`，提交以下信息：
- 举报类型
- 详细说明
- 是否实名展示
- 是否愿意配合管理员补充材料

提交后：
- 举报写入系统
- 管理员可在后台举报列表中查看并处理
- 如举报对象为违规用户，管理员可直接封禁或解除封禁

## 9. 管理后台
管理员进入后台后可执行以下操作：
- 查看简化后的运营摘要与轻量看板
- 查看待审核商品数量
- 查看待处理举报数量
- 审核商品是否恢复展示或下架
- 查看用户治理列表
- 直接封禁或解除封禁普通用户
- 通过举报结果直接触发封禁用户
- 查看最近操作留痕
- 查看举报备注、商品/用户目标和处理状态

后台页面默认也是折叠式结构，点击相应区块后展开详情。

## 9.2 用户治理说明
- 普通用户同时承担买家和卖家身份，因此封禁针对的是统一账号，不区分“买家账号”和“卖家账号”
- 用户被封禁后：
  - 不能登录系统
  - 不能发起举报
  - 不能执行发布、下单、发消息等关键写操作
- 管理员解除封禁后，账号恢复正常使用

## 10. 使用注意事项
- 当前系统聊天模块为 HTTP 落库 + Socket.IO 演示级实时推送模式
- 完整 JWT 鉴权与刷新机制仍未接入，当前以课程设计可演示闭环为主
- 若浏览器本地登录态异常，可重新登录以刷新当前身份
- “想要”列表当前保存在浏览器本地，不同浏览器或不同设备之间不会自动同步
