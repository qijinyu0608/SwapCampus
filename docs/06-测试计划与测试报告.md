# 测试计划与测试报告

## 1. 测试目标

验证当前系统的核心交易、校园服务、消息、治理和部署链路可运行。

## 2. 覆盖范围

- 认证注册登录
- 商品发布、搜索、详情、收藏
- 订单创建、完成、评价、申诉
- 消息会话、发送、实时追加
- 校园服务发布、接单、完成、收藏
- 用户资料、关注、信用中心
- 后台审核、举报、申诉、实名审核、封禁
- Docker Compose 启动
- 前端构建与后端测试

## 3. 当前测试环境

- 前端：React 18 + Vite
- 后端：NestJS + Prisma
- 数据库：MySQL 8
- 对象存储：MinIO
- 认证：SuperTokens
- 容器：Docker Compose

## 4. 数据口径

### 4.1 默认初始化基线

- 空库建表
- 无默认账号
- 无默认商品、订单、消息、校园服务

### 4.2 可选演示种子基线

手动执行 `npm run db:reset-and-seed-demo --prefix backend` 后：

- 用户：10
- 商品：30
- 校园服务：18
- 商品订单：6
- 校园服务订单：4
- 举报：4

## 5. 已执行验证

### 5.1 自动化验证

- 后端：`npm test --prefix backend`
- 前端：`npm run build --prefix frontend`
- CI：GitHub Actions 执行后端测试和前端构建

### 5.2 部署验证

- `make init`
- `make start`
- `curl http://127.0.0.1:3001/api/health`

### 5.3 业务联调

- 注册与登录
- 上传图片并发布商品
- 收藏商品并查看收藏页
- 创建订单、确认完成、提交评价
- 提交订单申诉
- 打开发消息页发送文本或附件
- 发布校园服务并接单
- 打开信用中心执行签到和任务领取
- 后台处理商品、举报、申诉和实名状态
