# 测试计划与测试报告

## 1. 目标与结论

本轮测试按用户要求落地为三层：

- 单元测试：70% 目标
- 集成 / 接口测试：20% 目标
- E2E：10% 目标

本次已经补齐：

- 前端单元 / 页面行为测试 27 个文件，89 个用例
- 后端单元 / 服务 / 控制器测试 46 个文件，224 个用例
- 黑盒 HTTP 集成测试脚本 1 个，10 个接口检查点
- Playwright E2E 脚本 1 个，9 条用户链路

当前真实覆盖率没有达到“整个项目 85% 以上”的目标。按本次实际产出的 coverage 数据：

- 前端 statements：`24.05%`
- 后端 statements：`67.19%`
- 以前后端 `coverage-final.json` 合并计算的项目级 statements 粗口径：`35.53%`

原因很直接：前端仍有大量大型页面、组件和路由未进入自动化覆盖，尤其 `AdminPage.tsx`、`ProfilePage.tsx`、`MessagesPage.tsx`、`CampusServicesPage.tsx` 等超长页面。
