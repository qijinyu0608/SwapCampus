# 测试计划与测试报告

## 1. 目标与结论

本轮测试按用户要求落地为三层：

- 单元测试：70% 目标
- 集成 / 接口测试：20% 目标
- E2E：10% 目标

本次已经补齐：

- 前端单元 / 页面行为测试 42 个文件，176 个用例
- 后端单元 / 服务 / 控制器测试 65 个文件，287 个用例
- 黑盒 HTTP 集成测试脚本 1 个，10 个接口检查点
- Playwright E2E 脚本 1 个，15 条用户链路

当前真实覆盖率在“以前后端 `coverage-final.json` 合并计算的项目级 statements 粗口径”下，已经达到“整个项目 85% 以上”的目标。按本次实际产出的 coverage 数据：

- 前端 statements：`88.75%`
- 后端 statements：`74.98%`
- 以前后端 `coverage-final.json` 合并计算的项目级 statements 粗口径：`85.04%`

这意味着 statements 指标已经跨过 `85%+`，但这个结论依赖前后端 coverage 汇总口径；如果单独看后端 statements、整体 branches / functions 和真实 E2E 完整链路，仍有明显补强空间。当前剩余缺口主要集中在：

- 前端 `CampusServicesPage.tsx`、`ProfilePage.tsx` 与少量零覆盖共享组件
- 前端大型页面的深层分支、消息流与异常态
- 后端 `users.service.ts`、`vendure.service.ts`、`reports.service.ts`、`admin.service.ts` 等长服务的边界路径
