# T-03 周进度汇报表

## 本周问题与处理
- 问题：Docker 环境下 Prisma engine 与 OpenSSL 兼容性不稳定。
  - 处理：在 backend Dockerfile 中显式安装 `openssl`，并在构建阶段执行 `npx prisma generate`。
- 问题：首页和详情页默认态信息铺得过满，像课程作业展示页。
  - 处理：改成默认简洁、细节折叠、操作后置展开的交互方式。
- 问题：宿主机高版本 Node 对前端 Rollup 原生依赖不稳定。
  - 处理：前端构建脚本固定使用 `Node 20`。
