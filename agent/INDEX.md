# Agent Index

`agent/` 目录是本仓库当前有效工程规范的主入口。

## 1. 目录结构

- `governance/`
  - 工程文档治理、规范更新规则、单一事实源原则
- `domain/`
  - 业务边界、分类体系等领域约束
- `architecture/`
  - 实现分层、模块职责、规则收口原则
- `data/`
  - 数据库、状态模型、商品数据结构
- `ui/`
  - 前端视觉与样式规范
